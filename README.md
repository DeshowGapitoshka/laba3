# lr3

## Пример запуска программы
./solution --method sort   вход.txt выход.txt
./solution --method heap   вход.txt выход.txt
./solution --method select вход.txt выход.txt

Для вычисления медианы используйте
./solution --method sort   вход.txt выход.txt --count число_повторов
./solution --method heap   вход.txt выход.txt --count число_повторов
./solution --method select вход.txt выход.txt --count число_повторов
